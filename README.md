## What I'm building

**[Maven](https://github.com/sparsh-j01/maven-ai)** — real-time voice mock interviews.
A long-lived stateful voice worker sepweb app, a turn-based
STT → LLM → TTS pipeline over LiveKit/WebRTC, a tool-driven state machine, a live coding
round graded against hidden tests in a-scored reports.
`Next.js 15 · TypeScript · Python · LiveKit · Postgres/pgvector · Inngest`

**[Paper trading platform](https://github.com/sparsh-j01/ledgr)** — a matching engine, written
the boring correct way: limit and markrity, an order book that
stays consistent under concurrent fills.
`Node · TypeScript · Postgres · Redis`
